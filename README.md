# Chamado-Web
Em pequenas empresas, escolas e setores de TI, os pedidos de suporte são feitos por WhatsApp, papel ou verbalmente, o que gera:  perda de solicitações  falta de prioridade  dificuldade de acompanhamento  👉 O HelpDesk+ centraliza os chamados em uma aplicação web simples e eficiente.  🧠 Objetivo do Sistema  Permitir que usuários registrem chamados
